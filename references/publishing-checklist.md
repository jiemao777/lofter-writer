## Preflight Questions

Answer these privately before final packaging:

- Is the work original, fanwork, translation, remix, adaptation, or repost?
- Did AI materially assist the text, image, video, title, tags, summary, or editing?
- Does the work involve minors, real people, privacy, explicit sexual content, self-harm, violence, harassment, misinformation, or sensitive public events?
- Is the user asking for gifts, paid return gifts, commissions, traffic growth, or platform exposure?
- Does the fandom have known tag customs such as CP direction, single-character tag avoidance, spoiler tags, or non-CP tags?

If any answer creates policy or platform risk, load [compliance-and-boundaries.md](./compliance-and-boundaries.md).

## Publication Package Fields

For a publish-ready package, include only the fields that fit the work:

- Final title
- Opening note or one-sentence hook
- Short summary
- Content notes or warnings
- AI disclosure note when needed
- Tag set, grouped and kept compact
- Collection name or chapter numbering when relevant
- Comment prompt that invites real discussion
- Gift/return-gift caution when monetization is discussed

## Tag Check

Use a compact 1-10 tag set unless the user has a strong fandom reason to do otherwise.

Default groups:

- CP or relationship tag
- Character tag only when fandom etiquette allows it
- IP/world tag
- Form tag, such as forum thread, chat log, reaction, daily, serial, short story
- Mood/content tag, such as sweet, HE, angst, comedy, modern AU, canon-adjacent
- AI tag, such as `#AI生成#` or `#AI辅助#`, when AI materially assisted the post

Do not:

- Add unrelated hot tags for reach
- Guess CP direction when AB/BA matters
- Push CP works into single-character tags if the fandom commonly treats that as disruptive
- Use tag stuffing, repeated tags, or irrelevant tags to occupy a tag page

## AI Disclosure Check

If AI materially assisted the work:

- Add `#AI生成#` or `#AI辅助#` where visible.
- Use LOFTER's creator declaration when available.
- Add a plain note if the post format would otherwise hide the AI role.
- Do not remove, alter, or hide AI labels, metadata, or watermarks.
- Do not describe AI-generated work as hand-drawn, original human-only writing, real testimony, or official/canon material.

Suggested note:

```text
创作说明：本文有 AI 辅助参与构思/润色/初稿生成，已由作者人工修改与审核。
```

Adjust the verbs honestly. Do not use this note if it overstates human involvement.

## Rights And Source Check

Before publication or monetization:

- Credit the source IP when relevant.
- Do not reproduce large passages from the source material.
- Do not repost another creator's work unless authorization and attribution are clear.
- Do not use community works for AI training, style transfer, or "AI washing" without explicit written authorization.
- For borrowed screenshots, translations, lyrics, images, edits, or templates, ask whether the user has rights before including them in a post package.
- For fanwork gifts or paid extras, warn that monetization increases copyright and platform-rule risk.

## Gift And Monetization Check

When the user asks about gifts, paid return gifts, or revenue:

- Say that exact eligibility, limits, service fees, tax handling, withdrawal windows, and thresholds can change.
- Recommend checking the current in-app terms before planning income.
- Do not use gifts for crowdfunding, donations, gambling, lotteries, product sales, or unrelated inducements.
- Do not lock safety warnings, AI disclosure, or essential context behind paid content.
- Keep return gifts related to the work and original or authorized.

## Final Output Pattern

For a `~publish-check`, return:

1. `Can publish`: yes / revise first / do not publish
2. `Blocking issues`: only issues that must be fixed
3. `Recommended fixes`: concise, actionable edits
4. `Final package`: title, summary, notes, tags, and CTA if safe

Do not invent official guarantees about exposure, approval, monetization, or review outcomes.
