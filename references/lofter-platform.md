# LOFTER Platform Notes

Use this file when you need platform-fit facts rather than literary guidance.

## Official Public Facts

The following points come from public LOFTER pages and are stable enough to guide this skill:

- LOFTER exposes multiple publish entry types, including text, image, music, video, and long article style routes.
- Community and discovery are heavily organized around tags, topic pages, and interest-based browsing.
- Public community rules prohibit illegal content, harassment, infringement, and other abusive behavior.
- Gift or reward features are governed by separate service terms and should only be used for compliant content.

## Practical Implications For This Skill

### 1. Optimize For Tag Discovery

LOFTER readers often discover works through tags before they discover authors. Treat the tag set as a distribution surface, not as an afterthought.

Default tag order:

1. CP
2. character names
3. IP or canon
4. format
5. setting or tone

### 2. Keep Packaging Compact

For most text posts, the package should include:

- a focused title
- a short hook or summary
- warnings only when relevant
- a clean tag set

Do not turn the post intro into a synopsis wall.

### 3. Do Not Hardcode Monetization Claims

Product rules for gifts, paid features, creator programs, and thresholds can change. If the user asks about current requirements, verify them from live official pages first.

### 4. Stay Within Publicly Safe Constraints

When packaging or revising, avoid:

- infringement framing
- abusive behavior
- content that obviously conflicts with public community norms
- spammy tag stuffing
