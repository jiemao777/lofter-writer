# Mode Routing

Use this file when the user knows the feeling they want but not the format name.

## Routing Table

### Sweet, light, easy to share

Recommended:

- chat format
- forum format
- reaction thread

Why:

- fast entry
- low reading friction
- easy punchlines

Risk:

- can feel thin if there is no emotional spine

## Tension, yearning, inner pull

Recommended:

- letter
- diary
- dual POV

Why:

- strong access to subtext
- good for longing and misread emotions

Risk:

- can become repetitive if every beat is introspection

## Fast heat, high engagement, short-form momentum

Recommended:

- forum snippets
- group chat
- staged reaction format

Why:

- easy to serialize
- easy to tag
- strong cold-start potential

Risk:

- weak world-building unless anchored by a sharp hook

## Heavy emotion, apology, breakup, reunion

Recommended:

- confession transcript
- letter
- straight narrative with narrow POV

Why:

- supports escalation and payoff
- clearer emotional curve

Risk:

- melodrama if the language gets generic

## Canon remix, setting showcase, premise-first AU

Recommended:

- system prompt fiction
- rules or handbook format
- observation log
- mixed format with short prose bridges

Why:

- lets the concept carry the read
- useful when premise is the main novelty

Risk:

- too much scaffolding, not enough scene

## Ensemble chaos, misunderstanding, comedy pileup

Recommended:

- forum plus prose bridge
- multi-thread chat
- faux records or screenshot style

Why:

- supports many voices quickly
- natural momentum from misunderstanding

Risk:

- character voices blur if not differentiated

## Output Rules By Format

## Chat And Forum

- keep turns short
- give each voice a habit or rhythm
- insert one or two concrete scene anchors so the whole piece is not floating text

## Letter And Diary

- give the piece a reason to exist
- make the writer's blind spot visible
- avoid pure summary of events

## Dual POV Or Straight Narrative

- choose one emotional engine
- keep scene order readable
- do not let format-switching break immersion

## Mixed Format

- one format should lead
- the other format should add contrast, not noise
- signal transitions clearly
